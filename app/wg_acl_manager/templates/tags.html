Gruppen

Gruppen fassen Clients zusammen, damit ACL-Regeln nicht IP fuer IP, sondern auf eine ganze Klasse von Peers zielen koennen - z.B. "erlaube Zugriff auf alle MikroTiks". Mitglieder werden direkt hier angehakt/abgehakt und sofort uebernommen. Wird eine Gruppe geloescht, verschwinden auch Regeln, die auf sie zielten - betroffene Clients danach erneut "anwenden" (siehe "Berechtigungen").
