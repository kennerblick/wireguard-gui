Gruppen

Gruppen fassen Clients zusammen, damit ACL-Regeln nicht IP fuer IP, sondern auf eine ganze Klasse von Peers zielen koennen - z.B. "erlaube Zugriff auf alle MikroTiks". Ein Client kann mehreren Gruppen angehoeren; die Zuordnung erfolgt auf dem Dashboard bei jedem Client. Wird eine Gruppe geloescht, verschwinden auch Regeln, die auf sie zielten - betroffene Clients danach erneut "anwenden".
