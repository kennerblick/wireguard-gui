Client bereitstellen

Halbautomatische Einrichtung eines neuen WireGuard-Clients in zwei Schritten: (1) Config/Skript für den neuen Client generieren und auf dem Zielgerät ausführen - der private Schlüssel wird dabei nur lokal auf diesem Gerät erzeugt und verlässt es nie; (2) den dabei ausgegebenen Public Key hier eintragen, um den Peer auf dem WireGuard-Server zu registrieren.

Schritt 1: Config/Skript generieren

Vorgeschlagene IP ist die nächste freie im IP-Bereich des oben gewählten Typs (Server/Router/Client haben getrennte Bereiche) - bei Bedarf überschreiben. Linux: Bash-Skript auf dem neuen Rechner mit sudo ausführen. Windows: PowerShell-Skript als Administrator ausführen (benötigt installiertes WireGuard für Windows). MikroTik: Skript-Inhalt komplett ins RouterOS-Terminal (Winbox oder SSH) einfügen. "Verwaltete Netze": falls der Router ein eigenes LAN dahinter hat (z.B. 192.168.88.0/24), hier eintragen (mehrere durch Komma getrennt) - erzeugt die passenden Firewall-Freigaben im Skript und wird in Schritt 2 automatisch in die AllowedIPs des Peers auf dem Server übernommen, damit Rückverkehr zu diesem Netz tatsächlich geroutet wird.

Schritt 2: Peer auf dem Server registrieren

Trägt den Peer live per wg set ein (wirkt sofort, ohne Neustart) und hängt einen [Peer]-Block mit #Name-Kommentar an die Server-Config an (damit er einen Neustart übersteht). Legt zusätzlich einen eingeschränkten Client-Datensatz ohne Regeln in dieser App an, mit dem hier gewählten Typ (bei angegebenen "Verwalteten Netzen" automatisch "Router"), und weist automatisch eine zur Plattform passende Gruppe zu (z.B. "mikrotik") - unter "Gruppen" frei änderbar. "Verwaltete Netze" (falls angegeben) werden zusätzlich zur eigenen Tunnel-IP in die AllowedIPs dieses Peers auf dem Server aufgenommen und als Rule-Ziel-Vorschlag hinterlegt - nachträglich änderbar über die Client-Karte unter "Berechtigungen".
